## 버전 비교 기능 추가

### 범위

src/views/schedule/Step5Result.vue

### 문제점

UI 가 비교를 위해 직관적이지 못하다.

### 예상 시나리오

사용자가 비교를 위한 버전을 선택한다. 그러면 팝업이 생성된다.

- 선택하면 먼저 Off 요청 사항이 어떻게 다른지 보여준다.
- 다음 단계로는 각 버전이 법적 기준을 준수하는지 확인한다.
  - 법적 기준 준수 여부 확인
    - NOD 금지, 3연속 야간 근무 금지, 야간 근무를 2일 연속한 경우 48시간 이상 휴식 보장, 야간 근무는 월 15회 이하 제한
  - 요구 사항 충족 확인
    - 일별 필요 인력, Off 요청 일수 및 Off 수락 일수
- 다음 단계에서 어떤 버전을 최종으로 선택할 것인지 확정한다.
