병원 담당자가 로그인 했을 때 처음 보이는 화면을 개선해야 한다.

일단 대시보드에 접근하면 필수 정보 (병원 정보, 병동 정보, 직원 정보 등)이 기입이 되어 있는지 확인해야 한다.

필수 정보가 입력이 안되어 있는 경우

- 온보딩 페이지가 등장하여 사용자가 쉽게 정보를 등록할 수 있도록 한다.

필수 정보가 이미 입력된 경우, 기본적으로 3개 섹션(탑메뉴)을 선택하여 진행할 수 있다

- 기본 정보 (병원 정보, 병동 정보, 직원 정보) 등을 수정하고 확인하는 섹션
- 다음달 근무표 생성을 위한 섹션
- 지난 근무표 생성 결과를 확인하고 병동별로 직원들의 근무 실적 확인, 공정성 확인 등을 위한 섹션
