# P5-2.1: Master Data UX Design

## Overview

Six-tab layout in `OrganizationManagement.vue`. Each tab is a standalone component with its own load/save lifecycle.

---

## Tab: 기본 정보 (OrgInfoTab)

```
┌─────────────────────────────────────────┐
│ 조직명  [세브란스병원              ]      │
│ 유형    [병원 ▼]                         │
│                              [저장]      │
└─────────────────────────────────────────┘
```

- `NInput` for name
- `NSelect` for type (OrganizationType options)
- Save calls `updateCurrentOrganization()` in `organizationStore`

---

## Tab: 시프트 (ShiftManagementTab)

```
┌────────────────────────────────────────────────────┐
│ 시프트 목록                              [+ 추가]   │
├──────┬──────┬──────────┬──────┬────────────────────┤
│ 코드 │ 이름 │ 색상     │ 시간 │ 작업               │
├──────┼──────┼──────────┼──────┼────────────────────┤
│ D    │ 낮   │ ██ #...  │ 07:00│ [수정] [삭제]       │
│ E    │ 저녁 │ ██ #...  │ 15:00│ [수정] [삭제]       │
│ N    │ 밤   │ ██ #...  │ 23:00│ [수정] [삭제]       │
└──────┴──────┴──────────┴──────┴────────────────────┘
```

- `NDataTable` with columns: code, name, color_code (swatch), start_time/end_time, actions
- Add/edit → `NModal` with form
- Delete → `NPopconfirm` confirmation

## Tab: 근무 제약 (ConstraintSettingsTab)

```
┌────────────────────────────────────────────┐
│ 최대 연속 N근무          [  3  ] 회         │
│ 주 평균 근무시간         [ 40  ] 시간        │
│ 주 최대 근무시간         [ 52  ] 시간        │
│ 주 휴무일               [  2  ] 일          │
│                                            │
│ 시프트별 최소 휴식시간                      │
│   D 근무 후   [ 24 ] 시간                   │
│   E 근무 후   [ 24 ] 시간                   │
│   N 근무 후   [ 36 ] 시간                   │
│                                            │
│                                   [저장]   │
└────────────────────────────────────────────┘
```

- All `NInputNumber` components (min=0)
- Shifts list for minimum rest hours is dynamic (from `orgStore.shifts`)
- Saves to `organization_settings` via `organizationMasterStore.saveSettings()`

## Default Data Policy

When a new organization is created, the following seed data should be auto-created (migration 009 backfill pattern):

- Shifts: D (낮, #FF6B6B), E (저녁, #4ECDC4), N (밤, #45B7D1), O (휴일, #96CEB4)
- Skills: GENERAL (일반)
- Ranks: RN (일반 간호사)
