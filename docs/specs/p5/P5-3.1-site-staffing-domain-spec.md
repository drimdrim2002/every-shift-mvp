# P5-3.1: Site Staffing Domain Specification

## Domain Model

### Table: `site_staffing_requirements` (migration 007)

This is the **service-native** staffing requirements table. The legacy `site_requirements` table is used by the MVP schedule wizard until P6 migrates it.

| Column          | Type        | Nullable | Notes                                  |
|-----------------|-------------|----------|----------------------------------------|
| id              | UUID PK     | NO       | gen_random_uuid()                      |
| organization_id | UUID FK     | NO       | → organizations.id ON DELETE CASCADE   |
| site_id         | UUID FK     | NO       | → sites.id ON DELETE CASCADE           |
| shift_id        | UUID FK     | NO       | → shifts.id ON DELETE CASCADE          |
| day_of_week     | INTEGER     | NO       | 0=Sunday, 1=Monday … 6=Saturday        |
| required_count  | INTEGER     | NO       | >= 0 (CHECK constraint)                |
| skill_id        | UUID FK     | YES      | → skills.id ON DELETE SET NULL         |
| rank_id         | UUID FK     | YES      | → ranks.id ON DELETE SET NULL          |
| created_at      | TIMESTAMPTZ | NO       |                                        |
| updated_at      | TIMESTAMPTZ | NO       |                                        |

### Unique Index

```sql
CREATE UNIQUE INDEX uq_site_staffing_requirements_scope ON site_staffing_requirements(
  organization_id,
  site_id,
  shift_id,
  day_of_week,
  COALESCE(skill_id, '00000000-0000-0000-0000-000000000000'::UUID),
  COALESCE(rank_id,  '00000000-0000-0000-0000-000000000000'::UUID)
);
```

### Semantics

- `skill_id = null` → applies to **all** skills (base requirement)
- `rank_id = null` → applies to **all** ranks (base requirement)
- Both null → total base requirement for this site/shift/day combination
- Non-null skill/rank → specialized overlay requirement
