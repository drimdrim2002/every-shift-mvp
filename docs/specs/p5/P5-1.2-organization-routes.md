# P5-1.2: Organization Management Routes & IA

## Route Decision: Single Page + NTabs

Instead of 6 separate routes, a **single route with NTabs** is used to reduce route guard duplication and simplify breadcrumbs.

| Route                  | Component                        | Guard               |
|------------------------|----------------------------------|---------------------|
| `/admin/organization`  | `OrganizationManagement.vue`     | `meta.roles: ['super', 'admin']` |

## File Structure

```
src/views/admin/
  OrganizationManagement.vue       ← main container + NTabs

src/components/admin/
  OrgInfoTab.vue                   ← 기본 정보 (name, type)
  ShiftManagementTab.vue           ← 시프트 CRUD
  ConstraintSettingsTab.vue        ← 근무 제약 폼
  SkillManagementTab.vue           ← 스킬 CRUD
  RankManagementTab.vue            ← 직급 CRUD
  SiteManagementTab.vue            ← 사이트 + 요일별 인원
```

## Sidebar Menu

Add to `src/components/layout/Sidebar.vue`:

```typescript
// Show only when accessState is 'super_active' or 'admin_active'
{
  label: '조직 관리',
  path: '/admin/organization',
  icon: 'BuildingIcon',
  condition: ['super_active', 'admin_active'],
}
```

## Super Admin: Org Selector

When `accessState === 'super_active'`, render an `NSelect` dropdown at the top of `OrganizationManagement.vue` to switch between organizations. Admin users see only their own organization without a selector.

## Route Registration (in `src/router/index.ts`)

Add inside the authenticated `'/'` children array:

```typescript
{
  path: 'admin/organization',
  name: 'AdminOrganization',
  component: () => import('@/views/admin/OrganizationManagement.vue'),
  meta: {
    title: '조직 관리',
    requiresAuth: true,
    roles: ['super', 'admin'],
  },
},
```

## Route Guard Logic

In the router's `beforeEach`, add RBAC check after auth:

```typescript
if (to.meta.roles) {
  const rbacStore = useRbacStore()
  const state = rbacStore.accessState
  const allowedStates: AccessState[] = ['super_active', 'admin_active']
  if (!allowedStates.includes(state)) {
    next('/')
    return
  }
}
```
