# P5-3.5: Monthly Application Test Scenarios

## Composable: `useSiteStaffingRequirements`

File: `src/composables/useSiteStaffingRequirements.ts`

### Key Function Signature

```typescript
function expandToMonth(
  reqs: SiteStaffingRequirement[],
  yearMonth: string           // "YYYY-MM" format
): MonthlyRequirement[]
```

This function is the bridge between weekly requirements (stored in DB) and per-day
requirements consumed by the AI Solver (P7-1.1).

---

## Test Scenarios

### TC-1: Normal Month (2026년 3월, 31일)

| Input                                  | Expected Output                              |
|----------------------------------------|----------------------------------------------|
| 1 requirement: dayOfWeek=1 (Mon), count=3 | 5 entries (all Mondays: Mar 2,9,16,23,30) |
| yearMonth = "2026-03"                  | 5 × requiredCount=3                          |

### TC-2: February (평년 2025, 28일)

| Input          | Expected           |
|----------------|--------------------|
| yearMonth = "2025-02" | 28 days total |
| dayOfWeek=0 (Sun) count=2 | 4 entries (Feb 2,9,16,23) |

### TC-3: Leap Year February (윤년 2028, 29일)

| Input          | Expected           |
|----------------|--------------------|
| yearMonth = "2028-02" | 29 days total |
| dayOfWeek=3 (Wed) count=4 | 5 entries (Feb 1,8,15,22,29) |

### TC-4: Sunday-Start Month (2026년 9월)

| Input                  | Expected                                   |
|------------------------|--------------------------------------------|
| yearMonth = "2026-09"  | Sep 1 = dayOfWeek 2 (Tuesday)              |
| dayOfWeek=2 count=3    | Sep 1 gets requiredCount=3                 |

> Verify with: `new Date(2026, 8, 1).getDay()` = 2 ✅

### TC-5: Empty Requirements

| Input                        | Expected                |
|------------------------------|-------------------------|
| reqs = []                    | returns []              |
| yearMonth = "2026-03"        | No entries emitted      |

### TC-6: Multiple Requirements Same Day

| Input                                       | Expected                    |
|---------------------------------------------|-----------------------------|
| D-shift Mon count=3, E-shift Mon count=4    | 2 entries for each Monday   |

### TC-7: Skill-Filtered Requirement

| Input                                                    | Expected                              |
|----------------------------------------------------------|---------------------------------------|
| dayOfWeek=1, shiftId=E, skillId="ICU-skill-uuid", count=2 | All Mondays get ICU E-shift=2 entry |
| skillId is non-null                                      | Propagated to MonthlyRequirement.skillId |

## P7-1.1 Readiness Check

The AI Solver (P7-1.1) needs:

```typescript
// P7-1.1 will call:
const { expandToMonth } = useSiteStaffingRequirements()

const monthReqs = expandToMonth(
  await loadRequirements(orgId, siteId),
  '2026-03'
)
// monthReqs is ready to be sent to OptaPlanner as scheduling constraints
```

✅ `expandToMonth` returns `MonthlyRequirement[]` with:
- `date` (YYYY-MM-DD) — matches solver's date format
- `shiftId` — UUID reference to shifts table
- `requiredCount` — direct solver input
- Optional `skillId`/`rankId` — solver skill constraint
