# P5-3.3: Site Staffing Grid Editor UI Design

## Grid Layout

Rows = organization shifts (dynamic), Columns = 7 days of week (Sunday–Saturday).

```
         │ 일(0) │ 월(1) │ 화(2) │ 수(3) │ 목(4) │ 금(5) │ 토(6) │
    D    │  3    │  3    │  3    │  3    │  3    │  3    │  3    │
    E    │  3    │  4    │  4    │  4    │  4    │  4    │  3    │
    N    │  3    │  3    │  3    │  3    │  3    │  3    │  3    │
    H    │       │  1    │  1    │  1    │  1    │  1    │       │
```

- Each cell = `NInputNumber` (min=0, max=999, style="width: 60px")
- Row header = shift code + color swatch badge
- Column header = Korean day name + day index

## Skill / Rank Filter

```
┌────────────────────────────────────────────┐
│ 스킬 [전체 ▼]   직급 [전체 ▼]              │
└────────────────────────────────────────────┘
```

- "전체" = null (base requirement)
- Dropdown options loaded from `orgStore.skills` / `orgStore.ranks`
- Changing filter loads a different set of `site_staffing_requirements` rows

## Data Structure

```typescript
// Grid state: gridData[shiftId][dayOfWeek] = requiredCount
const gridData = ref<Record<string, Record<number, number>>>({})

function initGrid(shifts: Shift[]): void {
  for (const shift of shifts) {
    gridData.value[shift.id] = {}
    for (let d = 0; d < 7; d++) {
      gridData.value[shift.id][d] = 0
    }
  }
}

function populateGrid(reqs: SiteStaffingRequirement[]): void {
  for (const req of reqs) {
    if (gridData.value[req.shiftId]) {
      gridData.value[req.shiftId][req.dayOfWeek] = req.requiredCount
    }
  }
}
```

## Save Flow

```
[일괄 저장] button clicked
  → Convert gridData to SiteStaffingRequirementInput[]
  → Call useSiteStaffingRequirements().saveAll(inputs)
  → Success: show NMessage "저장되었습니다"
  → Error: show NMessage error text
```

```typescript
function buildInputs(
  orgId: string,
  siteId: string,
  skillId: string | null,
  rankId: string | null
): SiteStaffingRequirementInput[] {
  const inputs: SiteStaffingRequirementInput[] = []
  for (const [shiftId, days] of Object.entries(gridData.value)) {
    for (const [dow, count] of Object.entries(days)) {
      inputs.push({
        organizationId: orgId,
        siteId,
        shiftId,
        dayOfWeek: Number(dow),
        requiredCount: count,
        skillId,
        rankId,
      })
    }
  }
  return inputs
}
```

## Grid Rendering (SiteStaffingGrid.vue template sketch)

```html
<n-grid :cols="8">
  <n-gi />  <!-- empty header cell -->
  <n-gi v-for="day in days" :key="day.index">{{ day.label }}</n-gi>

  <template v-for="shift in shifts" :key="shift.id">
    <n-gi>
      <n-badge :color="shift.colorCode">{{ shift.code }}</n-badge>
    </n-gi>
    <n-gi v-for="day in days" :key="day.index">
      <n-input-number
        v-model:value="gridData[shift.id][day.index]"
        :min="0"
        size="small"
        style="width: 60px"
      />
    </n-gi>
  </template>
</n-grid>
```
