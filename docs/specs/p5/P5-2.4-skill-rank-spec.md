# P5-2.4: Skill & Rank Master Specification

## Skill

### Table: `skills` (migration 007)

| Column          | Type        | Notes                            |
|-----------------|-------------|----------------------------------|
| id              | UUID PK     | gen_random_uuid()                |
| organization_id | UUID FK     | → organizations.id ON DELETE CASCADE |
| code            | VARCHAR(50) | Uppercase, org-unique (UNIQUE constraint) |
| name            | VARCHAR(100)| Display name                     |
| created_at      | TIMESTAMPTZ | DEFAULT NOW()                    |

### TypeScript Interface (`src/types/skill.ts`)

```typescript
export interface Skill {
  id: string
  organizationId: string
  code: string
  name: string
  createdAt?: string
}
```

### Field Validation

- `code`: Uppercase alphanumeric (auto-uppercased in API). Max 50 chars. Org-unique.
- `name`: Max 100 chars. Required.

### Delete Policy

Block deletion if referenced in:
- `employee_skills.skill_id`
- `site_staffing_requirements.skill_id` (ON DELETE SET NULL — no block needed here, DB handles it)

> Note: `site_staffing_requirements.skill_id` has `ON DELETE SET NULL`, so deleting a skill won't block from that side. Only `employee_skills` can block via FK.

## Rank

### Table: `ranks` (migration 007 + credit in 012)

| Column          | Type           | Notes                            |
|-----------------|----------------|----------------------------------|
| id              | UUID PK        | gen_random_uuid()                |
| organization_id | UUID FK        | → organizations.id ON DELETE CASCADE |
| code            | VARCHAR(50)    | Uppercase, org-unique            |
| name            | VARCHAR(100)   | Display name                     |
| credit          | NUMERIC(10,2)  | Optional, added in migration 012 |
| created_at      | TIMESTAMPTZ    | DEFAULT NOW()                    |

### TypeScript Interface (`src/types/rank.ts`)

```typescript
export interface Rank {
  id: string
  organizationId: string
  code: string
  name: string
  credit?: number | null
  createdAt?: string
}
```

### Field Validation

- `code`: Same as skill code
- `credit`: Optional. If provided, must be >= 0. Displayed as decimal (e.g. 1.00).

### Credit Concept (for P6 Employee Management)

When a new employee is created and assigned a rank, `credit` from the rank is used as the employee's initial credit value. Example: LV1=1.0, LV2=2.0, LV3=3.0, LV4=4.0.

### Delete Policy

Block deletion if referenced in `site_staffing_requirements.rank_id`.
> `site_staffing_requirements.rank_id` is `ON DELETE SET NULL`, so no block from that side. Check direct FK references in employee tables.
