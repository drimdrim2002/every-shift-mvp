# P5-3.2: Site CRUD UX Design

## Components

```
src/components/admin/
  SiteManagementTab.vue      ← site list + add button + expansion
  SiteFormModal.vue          ← create/edit modal
  SiteStaffingGrid.vue       ← day-of-week × shift grid per site
```

## SiteManagementTab Layout

```
┌────────────────────────────────────────────────────────────┐
│ 사이트 목록                                     [+ 사이트]  │
├───────┬────────────────────┬───────────────────────────────┤
│ 코드  │ 이름               │ 작업                          │
├───────┼────────────────────┼───────────────────────────────┤
│ ▶ ICU │ 중환자실           │ [인원 설정] [수정] [삭제]      │
│ ▶ GW1 │ 병동 1             │ [인원 설정] [수정] [삭제]      │
└───────┴────────────────────┴───────────────────────────────┘
```

- `▶` row expander: clicking shows `SiteStaffingGrid` inline below the row
- "인원 설정" button: alternative to expanding — scrolls to/opens grid

## SiteFormModal

```
┌──────────────────────────────────────┐
│ 사이트 추가 / 수정                   │
├──────────────────────────────────────┤
│ 코드  [ICU          ]                │
│ 이름  [중환자실     ]                │
│                [취소]  [저장]        │
└──────────────────────────────────────┘
```

- Code auto-uppercased
- Duplicate code → inline error

## Delete Confirmation

```
이 사이트를 삭제하시겠습니까?
삭제하면 관련 인원 요구사항도 함께 삭제됩니다.

                        [취소]  [삭제]
```

If DB returns FK error (23503) despite cascade, show:
> "이 사이트는 현재 사용 중이어서 삭제할 수 없습니다."

## NDataTable Column Definition

```typescript
const columns = [
  { type: 'expand' },
  { key: 'code', title: '코드', width: 80 },
  { key: 'name', title: '이름' },
  {
    key: 'actions',
    title: '작업',
    render: (row: Site) => h(NSpace, null, {
      default: () => [
        h(NButton, { size: 'small', onClick: () => openStaffingGrid(row) }, '인원 설정'),
        h(NButton, { size: 'small', onClick: () => openEditModal(row) }, '수정'),
        h(NButton, { size: 'small', type: 'error', onClick: () => confirmDelete(row) }, '삭제'),
      ]
    })
  }
]
```
