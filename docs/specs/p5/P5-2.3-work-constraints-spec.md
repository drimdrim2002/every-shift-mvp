# P5-2.3: Work Constraints Specification

## Constraint Field Definitions

| Field                    | Storage Location                          | Type    | Default | Validation              |
|--------------------------|-------------------------------------------|---------|---------|-------------------------|
| 최대 연속 N근무          | `organization_settings.max_consecutive_night_shifts` | INTEGER | null    | null = no limit; >= 0   |
| 주 평균 근무시간 (목표)  | `organization_settings.work_constraints.weeklyTargetHours` | number  | 40      | > 0                     |
| 주 최대 근무시간         | `organization_settings.work_constraints.weeklyMaxHours`    | number  | 52      | >= weeklyTargetHours    |
| 주 휴무일                | `organization_settings.work_constraints.weeklyOffDays`     | number  | 2       | >= 0, <= 7              |
| 시프트별 최소 휴식시간   | `organization_settings.minimum_rest_hours`                 | JSONB   | D:24, E:24, N:36 | each value > 0 |

## work_constraints JSONB Schema

```json
{
  "weeklyTargetHours": 40,
  "weeklyMaxHours": 52,
  "weeklyOffDays": 2
}
```

## minimum_rest_hours JSONB Schema

```json
{ "D": 24, "E": 24, "N": 36 }
```

Key is shift code. Value is rest hours required after that shift type. The shift codes are dynamic (from `orgStore.shifts`) so the JSONB must support any shift code string.

## Frontend Validation

```typescript
function validateConstraints(c: WorkConstraints): string | null {
  if (c.weeklyTargetHours <= 0) return '주 평균 근무시간은 0보다 커야 합니다'
  if (c.weeklyMaxHours < c.weeklyTargetHours) return '주 최대 근무시간은 평균 이상이어야 합니다'
  if (c.weeklyOffDays < 0 || c.weeklyOffDays > 7) return '주 휴무일은 0~7 사이여야 합니다'
  return null
}
```

## Solver Integration (P7 Dependency)

These fields map directly to the OptaPlanner solver's constraint parameters:
- `weeklyTargetHours` → `WeeklyHoursTargetConstraint`
- `weeklyMaxHours` → `MaxWeeklyHoursConstraint`
- `weeklyOffDays` → `MinOffDaysConstraint`
- `max_consecutive_night_shifts` → `ConsecutiveNightShiftConstraint`
- `minimum_rest_hours[shiftCode]` → `MinRestBetweenShiftsConstraint`

P7-1.1 can read these directly from `organizationMasterStore.settings` without additional transformations.
