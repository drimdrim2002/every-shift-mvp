# P5-1.1: Organization Field Specification

## Scope

Organization management domain field definitions, RBAC rules, and TypeScript types.

## Table Field Matrix

### `organizations` (unchanged from migration 007)

| Column     | Type         | Nullable | Notes                                    |
|------------|--------------|----------|------------------------------------------|
| id         | UUID PK      | NO       | gen_random_uuid()                        |
| name       | VARCHAR      | NO       | Display name, e.g. "세브란스병원"         |
| type       | VARCHAR(20)  | NO       | See OrganizationType below               |
| created_at | TIMESTAMPTZ  | NO       | DEFAULT NOW()                            |
| updated_at | TIMESTAMPTZ  | NO       | DEFAULT NOW()                            |

> **Decision**: No additional columns needed on `organizations` itself. Extended settings go to `organization_settings`.

### `organization_settings` (extended by migration 012)

| Column                       | Type        | Nullable | Default            | Notes                              |
|------------------------------|-------------|----------|--------------------|------------------------------------|
| id                           | UUID PK     | NO       | gen_random_uuid()  |                                    |
| organization_id              | UUID FK     | NO       | UNIQUE             | → organizations.id                 |
| max_consecutive_night_shifts | INTEGER     | YES      | NULL (no limit)    | CHECK >= 0                         |
| minimum_rest_hours           | JSONB       | NO       | {}                 | { [shiftCode]: hours }             |
| work_constraints             | JSONB       | NO       | (see migration 012)| { weeklyTargetHours, weeklyMaxHours, weeklyOffDays } |
| created_at                   | TIMESTAMPTZ | NO       | NOW()              |                                    |
| updated_at                   | TIMESTAMPTZ | NO       | NOW()              |                                    |

#### `work_constraints` JSONB Schema

```json
{
  "weeklyTargetHours": 40,
  "weeklyMaxHours": 52,
  "weeklyOffDays": 2
}
```

#### `minimum_rest_hours` JSONB Schema

```json
{ "D": 24, "E": 24, "N": 36 }
```

## OrganizationType

```typescript
type OrganizationType = 'hospital' | 'fire' | 'police' | 'logistics' | 'production'
```

Current DB CHECK constraint only allows `'hospital' | 'fire' | 'police'`. When new types are added, a separate migration is required.

## RBAC Rules (P2 reference — do not redefine)

| Operation                    | super | admin (own org) | user |
|------------------------------|-------|-----------------|------|
| Read organization info       | ✅    | ✅              | ❌   |
| Update organization name/type| ✅    | ✅              | ❌   |
| Read settings                | ✅    | ✅              | ❌   |
| Update settings              | ✅    | ✅              | ❌   |

> Source: `docs/migration/RBAC_MATRIX.md`, `docs/migration/P1-2.2_RLS_POLICY_MATRIX.md`

## TypeScript Types (implemented in `src/types/organization.ts`)

```typescript
export type OrganizationType = 'hospital' | 'fire' | 'police' | 'logistics' | 'production'

export interface Organization {
  id: string
  name: string
  type: OrganizationType
  createdAt?: string
  updatedAt?: string
}

export interface WorkConstraints {
  weeklyTargetHours: number
  weeklyMaxHours: number
  weeklyOffDays: number
}

export type MinimumRestHours = Record<string, number>

export interface OrganizationSettings {
  id: string
  organizationId: string
  maxConsecutiveNightShifts: number | null
  minimumRestHours: MinimumRestHours
  workConstraints: WorkConstraints
  createdAt?: string
  updatedAt?: string
}
```
