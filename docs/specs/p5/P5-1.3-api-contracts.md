# P5-1.3: API Contracts

## Pattern Reference

All API files follow the `src/api/shift.ts` pattern:
- Private `XxxRow` interface (snake_case DB columns)
- Private `toXxx(row)` converter (snake_case → camelCase)
- Public async functions return domain types or throw Korean error messages
- No RPC — direct `.from()` Supabase calls
- Duplicate code: `error.code === '23505'` → "이미 존재하는 코드입니다"
- FK violation: `error.code === '23503'` → "사용 중이어서 삭제할 수 없습니다"

## API Files

### `src/api/organization-settings.ts`

```typescript
loadSettings(orgId: string): Promise<OrganizationSettings | null>
upsertSettings(orgId: string, settings: Partial<...>): Promise<OrganizationSettings>
```

Table: `organization_settings`
Conflict target: `organization_id`

### `src/api/site.ts`

```typescript
loadSites(orgId: string): Promise<Site[]>
createSite(orgId: string, data: Omit<Site, 'id'|'organizationId'|'createdAt'>): Promise<Site>
updateSite(siteId: string, data: Partial<...>): Promise<void>
deleteSite(siteId: string): Promise<void>
```

Table: `sites`
