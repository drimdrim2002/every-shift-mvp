# Slice3 랜딩페이지 콘텐츠 기획안

## 1. 목적

Slice3 랜딩페이지는 EveryShift를 처음 보는 간호사와 병동 근무표 담당자가 아래 세 가지 가치를 첫 화면에서 이해하도록 만든다.

1. AI가 병동 근무표 초안을 작성한다.
2. off 요청을 생성 전에 입력하고 반영을 시도한다.
3. 보건복지부 교대근무 가이드 기준의 위반 가능성을 결과 확인 단계에서 점검한다.

이 페이지의 대상은 일반 사용자가 아니다. D/E/N, OFF, NOD, NNN, 야간 개수, 필요 인력, off 요청 같은 용어를 아는 간호사와 병동 관리자라고 가정한다.

## 2. 핵심 메시지

### Hero H1

```text
AI가 병동 근무표 초안을 만들고,
가이드 위반 가능성까지 함께 점검합니다
```

### Hero 보조 문구

```text
EveryShift는 직원별 가능 근무, 전월 근무 이력, 병동별 필요 인력, off 요청을 반영해 근무표 초안을 생성합니다.
생성 후에는 주 52시간, NNN, NOD, 최소 휴식, 필요 인력 부족 같은 위험 항목을 한 화면에서 확인할 수 있습니다.
```

### 짧은 가치 문장

```text
오프를 먼저 반영하고, 위험 항목을 확인한 뒤, 바로 수정 가능한 근무표를 만듭니다.
```

## 3. 섹션 구성

### 3.1 Hero

목표: 첫 화면에서 “AI 생성 + off 선반영 + 위반 체크”가 동시에 보이게 한다.

표시 요소:

- 상단 작은 라벨: `간호사 근무표 생성 솔루션`
- H1: `AI가 병동 근무표 초안을 만들고, 가이드 위반 가능성까지 함께 점검합니다`
- 보조 문구: 직원 가능 근무, 전월 이력, 필요 인력, off 요청 기반 생성
- Primary CTA: `도입 문의하기`
- Secondary CTA: `로그인`
- 오른쪽 제품 미리보기:
  - D/E/N/OFF 근무표 그리드
  - `Off 요청 선반영 18건`
  - `미반영 Off 요청 3건: 사유 확인 필요`
  - `주 52시간 · NNN · NOD · 최소 휴식 체크`

### 3.2 Nurse Pain Points

목표: 간호사가 실제 듀티 작성에서 겪는 문제를 짧게 찌른다.

카피:

- `오프를 맞추면 NOD가 생기고, NOD를 피하면 야간 편차가 커집니다.`
- `전월 마지막 근무를 빼고 보면 최소 휴식 위반을 놓치기 쉽습니다.`
- `필요 인력 기준을 맞추다 보면 반영하지 못한 off 요청의 설명이 필요합니다.`

### 3.3 Core Values

세 개 카드로 구성한다.

1. `AI 근무표 초안 생성`
   - 직원 가능 근무, D/E/N 기준, 전월 5일 이력, 병동 필요 인력을 반영해 초안을 만든다.
2. `Off 요청 선반영`
   - 생성 전에 off 요청을 입력하고, 생성 결과에서 반영 여부를 확인한다.
3. `가이드 위반 가능성 체크`
   - 주 52시간, NNN, NOD, 최소 휴식, 필요 인력 부족을 결과 확인 단계에서 점검한다.

### 3.4 Workflow

간호사가 이미 아는 듀티 작성 흐름에 맞춰 보여준다.

```text
1. 병동 기준 입력
2. 직원 / 전월 근무 / off 요청 입력
3. AI 근무표 생성
4. 위반 가능성 및 미반영 요청 확인
5. 수정 후 Excel 내보내기
```

### 3.5 Trust Preview

목표: EveryShift가 단순 생성기가 아니라 “확정 전 검토 도구”라는 점을 전달한다.

표시할 항목:

- `하드 제약 위반 0건이면 확정 가능`
- `위반이 있으면 확정 전 원인 확인`
- `미반영 off 요청은 사유와 함께 표시`
- `후보안별 off 반영률, 야간/주말 편차 비교`

### 3.6 Pilot CTA

Slice3는 공개 랜딩 표면을 만드는 단계이고, 실제 문의 URL은 Slice5에서 안전하게 연결한다.

권장 카피:

```text
병동 근무표 작성 시간을 줄이고 싶다면 EveryShift 파일럿 도입을 문의해 주세요.
```

CTA:

- Primary: `도입 문의하기`
- Secondary: `로그인`

- 랜딩페이지의 기본 브랜드 표현은 E1 기준으로 맞춘다.

## 5. 표현 기준

### 사용해도 되는 표현

- `보건복지부 교대근무 가이드 기준의 위반 가능성 점검`
- `확정 전 위험 항목 확인`
- `주 52시간, NNN, NOD, 최소 휴식, 필요 인력 부족 체크`
- `off 요청을 생성 전에 입력하고 반영 여부를 확인`
- `반영되지 않은 off 요청의 사유 확인`
- `AI가 근무표 초안을 생성`

### 피해야 하는 표현

- `보건복지부 인증`
- `법적 100% 보장`
- `모든 off 요청 반영`
- `완전 자동 확정`
- `간호사가 검토하지 않아도 되는 근무표`
- `실제 병원이 즉시 셀프 가입 가능`

## 6. 고해상도 목업 제작 기준

목업은 데스크톱 첫 화면 기준으로 제작한다.

권장 화면:

- 크기: 1440 x 1200 이상
- 톤: 실제 SaaS 랜딩페이지, 간호사 대상 업무 도구
- 배경: white / slate 기반
- 강조색: emerald, sky, violet, amber warning
- 시각 요소:
  - 왼쪽에는 H1, 설명, CTA
  - 오른쪽에는 제품 UI 미리보기
  - 제품 UI에는 근무표 그리드, 위반 체크 패널, off 요청 카드가 함께 표시

목업에 들어갈 주요 텍스트:

```text
EveryShift
AI가 병동 근무표 초안을 만들고,
가이드 위반 가능성까지 함께 점검합니다
오프를 먼저 반영하고, 위험 항목을 확인한 뒤, 바로 수정 가능한 근무표를 만듭니다.
도입 문의하기
로그인

Off 요청 선반영 18건
미반영 Off 요청 3건
주 52시간 0
NNN 0
NOD 1
최소 휴식 0
필요 인력 부족 0
```

## 7. 근거

- 현재 제품 포지셔닝: 50명 이상 병동 수간호사를 위해 법적 제약과 사전 off 요청을 고려하면서 야간/주말 근무 편차와 작성 시간을 줄이는 솔루션
- Phase2 Trust Layer: 하드 제약 충족 증명, 미반영 off 요청 설명, 후보안 비교, 결과 확정 gate
- Solver 입력 구조: future `O` 요청은 `undesirable`로 전송되어 생성 전에 반영을 시도한다.
- 공식 지침 출처: 건강보험심사평가원은 2025-07-18 공지에서 `제2차 간호사 교대제 개선 시범사업` 지침이 보건복지부로부터 시달되었다고 안내했다.
