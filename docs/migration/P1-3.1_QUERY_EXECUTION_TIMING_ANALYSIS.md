## 4) P1-3.1 완료 판정용으로는 아직 시점이 아닌 쿼리

`POST-01 ~ POST-06`은 백필 DML 실행 이후(`P1-3.2`)에만 완료 판정 근거가 된다.

현재 실측 기준:
1. `POST-01`: 미충족 (`organization_settings/sites/ranks/skills = 0`)
2. `POST-02`: 미충족 (`source_count = 21`, `target_count = 0`)
3. `POST-03`: 미충족 (`remaining_null_site_id = 317`)
4. `POST-04/POST-05/POST-06`: 현재도 통과 가능(데이터가 아직 생성되지 않은 상태에서도 성립 가능)

`POST-07`은 정책 점검 성격이라 현재 실행 가능하지만, 본래 목적은 백필 직후 정책 확인이다.
