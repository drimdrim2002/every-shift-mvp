# 전역 RBAC 메뉴/라우트 권한 매트릭스

본 문서는 `REFINED_PRD.md`에 정의된 역할(super, admin, user)에 따른 프론트엔드 라우트 및 메뉴 접근 권한을 명세합니다. 이 매트릭스는 라우터 가드(`meta.roles`) 및 UI 요소의 노출(v-if 등) 기준이 됩니다.

## 1. 역할 정의
- **super**: 프로젝트 전체의 모든 권한을 가짐. (DB에서 직접 생성)
- **admin**: 소속된 조직 관리에 대한 모든 권한을 가짐.
- **user**: 허용된 메뉴에 대해서 허용된 권한을 가짐 (기본 직원).

## 2. 라우트 및 메뉴 접근 권한 매트릭스

| :--- | :--- | :--- | :--- | :--- | :--- |

## 3. 라우터 가드 구현 지침 (예정)

- **전역 가드(`beforeEach`)**: `meta.roles` 배열을 확인하여 현재 사용자의 역할이 배열에 포함되어 있지 않은 경우 `403 Forbidden` 페이지로 리다이렉트합니다.
- **Home(`/`) 리다이렉트**: 사용자가 로그인 후 `/` 로 접근 시, 역할이 `super` 또는 `admin`이면 `/dashboard/admin`으로, `user`이면 `/dashboard/employee`로 리다이렉트합니다.
- **`user` 권한 제한 적용**:
  - `user` 권한은 사이드바 LNB에서 '계정 관리', '조직 관리', '근무표 생성' 메뉴가 렌더링되지 않아야 합니다.
  - 직원 관리 메뉴 접근 시, 다른 직원의 목록을 볼 수 없거나 자신의 상세 정보 페이지(`/employees/me`)로 강제 라우팅되어야 합니다.
