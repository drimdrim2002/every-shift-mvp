# 전역 RBAC 메뉴/라우트 권한 매트릭스

본 문서는 `REFINED_PRD.md`에 정의된 역할(super, admin, user)에 따른 프론트엔드 라우트 및 메뉴 접근 권한을 명세합니다. 이 매트릭스는 라우터 가드(`meta.roles`) 및 UI 요소 노출(v-if) 기준이며, `tasks.json` 백로그 추적 기준입니다.

## 1. 역할 정의
- **super**: 프로젝트 전체의 모든 권한을 가짐 (DB에서 직접 생성).
- **admin**: 소속된 조직 관리에 대한 모든 권한을 가짐.
- **user**: 허용된 메뉴에 대해서 허용된 권한을 가짐.

| :--- | :--- | :--- | :--- | :--- | :--- |

## 3. 라우터 가드 구현 지침
- **전역 가드(`beforeEach`)**: `meta.roles` 배열을 확인하고 포함되지 않으면 `403` 또는 역할별 기본 홈으로 리다이렉트한다.
- **Home(`/`) 리다이렉트**: 로그인 후 `/` 접근 시 `super/admin -> /dashboard/admin`, `user -> /dashboard/employee`로 분기한다.
- **메뉴 숨김 정책**: `user`는 LNB에서 `계정 관리`, `조직 관리`, `근무표 생성` 메뉴를 렌더링하지 않는다.
- **직원 self-scope 강제**: `user`가 직원 관리 라우트 진입 시 `/employees/me`로 강제한다.
